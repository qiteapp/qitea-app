# قاعدة بيانات متاجر قطع الغيار — عملاء محتملون

أداة تبني قاعدة بيانات متاجر قطع غيار السيارات في السعودية من دليل
[موتري](https://ksa.motory.com/ar/الدليل/قطع-غيار-سيارات/)، وتخرج بجدول جاهز للتواصل:
**اسم المتجر، رقم الجوال، العلامات التجارية، المدينة، والموقع على الخريطة**.

بايثون ٣ فقط — **لا تحتاج تنصيب أي مكتبة** (`urllib` و `sqlite3` و `html.parser` من المكتبة القياسية).

## التشغيل

```bash
cd leads

# ١) الزحف على الدليل وبناء القاعدة (مع حفظ نسخة من الصفحات)
python3 cli.py crawl --max-pages 400 --delay 1 --save-html pages/

# ٢) تنقية الأرقام العامة ووسم المتاجر المكررة
python3 cli.py clean

# ٣) التصدير: CSV للإكسل + JSON + GeoJSON + خريطة تفاعلية
python3 cli.py export --all
```

النتائج في `out/`:

| الملف | الاستخدام |
|---|---|
| `out/leads.csv` | يفتح مباشرة في إكسل/Google Sheets بعناوين عربية |
| `out/leads.json` | للاستيراد في التطبيق أو Supabase |
| `out/leads.geojson` | لأي أداة خرائط (QGIS، Mapbox، Google My Maps) |
| `out/map.html` | خريطة تفاعلية: كل متجر نقطة، وفيها زر واتساب ومكالمة |

القاعدة نفسها في `leads.db` (SQLite) — تُفتح بأي عارض SQLite أو من بايثون.

### إن كان الزحف محجوباً عندك

شغّل الأداة على صفحات محفوظة، بدون إنترنت إطلاقاً:

```bash
# احفظ صفحات المتاجر من المتصفح (Ctrl+S) في مجلد pages/
python3 cli.py ingest pages/
python3 cli.py clean && python3 cli.py export --all
```

### أوامر أخرى

```bash
python3 cli.py stats                                  # ملخص: كم متجر، أكثر المدن والعلامات
python3 cli.py export --city الرياض --mobile-only      # من لديه جوال في الرياض فقط
python3 cli.py export --brand toyota --csv             # متاجر تويوتا
python3 cli.py contact 12 --channel whatsapp --status interested --outcome "طلب عرض أسعار"
```

## ما تفعله الأداة بالضبط

1. **الزحف** (`crawler.py`): يبدأ من صفحة القسم، يكتشف صفحات العلامات التجارية وصفحات
   الترقيم وصفحات المتاجر تلقائياً، بمهلة ثانية بين الطلبات، ويسجّل كل صفحة في
   `crawl_log` حتى يُكمل من حيث توقف. **يتوقف فوراً إذا منع `robots.txt` القسم.**
2. **الاستخراج** (`extract.py`): لا يعتمد على أسماء CSS في الموقع (لأنها تتغير)، بل على:
   - بيانات `JSON-LD` المنظمة (`LocalBusiness`/`AutoPartsStore`) — أدق مصدر،
   - روابط `tel:` و `wa.me` و روابط خرائط جوجل والإحداثيات داخل `iframe`،
   - النص الظاهر كحل أخير.
3. **التوحيد** (`normalize.py`):
   - الأرقام إلى صيغة دولية `+9665XXXXXXXX` مع تحديد المشغل (stc/موبايلي/زين)
     والتفريق بين الجوال والثابت والرقم الموحد (٩٢٠) والمجاني (٨٠٠)،
     ويفصل الأرقام الملتصقة ويتجاهل السنوات والأسعار،
   - المدينة من أي نص عربي أو إنجليزي (٤٤ مدينة مع مناطقها وإحداثياتها)،
   - العلامات التجارية من قاموس ٧٦ علامة، ويتعامل مع البادئات الملتصقة
     مثل «وكيا» و«بتويوتا» دون أن يُطابق «ألمانيا» كعلامة «مان».
4. **التنقية** (`cli.py clean`):
   - **الأرقام العامة**: رقم يظهر في أكثر من ٥ متاجر هو رقم دعم الدليل لا رقم المتجر،
     فيُحذف (وإلا امتلأت قائمتك برقم واحد مكرر). العدد قابل للتغيير بـ `--phone-threshold`.
   - **المكرر**: نفس الجوال، أو نفس الاسم في نفس المدينة → يبقى الأعلى تقييماً
     ويُوسم الباقي في `duplicate_of` (لا يُحذف، حتى تراجعه بنفسك).
5. **نقاط الجدوى** (`lead_score` من ١٠٠): الجوال ٤٠، واتساب ١٠، هاتف/موحد ١٠،
   إحداثيات دقيقة ١٥، مدينة ١٠، وعدد العلامات حتى ١٥. التصدير مرتب بها تنازلياً.

## بنية قاعدة البيانات

| الجدول | المحتوى |
|---|---|
| `stores` | المتاجر: الاسم، المدينة والمنطقة، الجوال وكل الأرقام، واتساب، العلامات، الإحداثيات ورابط الخريطة، التقييم، نقاط الجدوى، حالة التواصل |
| `contact_log` | سجل كل محاولة تواصل: القناة، النتيجة، الملاحظات |
| `crawl_log` | الصفحات التي تمت زيارتها، لاستكمال الزحف |
| `leads_ready` (عرض) | الجاهزون للتواصل: جوال موجود وغير مكرر، مرتبين بالجدوى |

## ملاحظات مهمة

- **`whatsapp` قد يكون افتراضاً**: إذا لم يوجد رابط واتساب صريح في الصفحة، تُستخدم
  قيمة الجوال كرقم واتساب محتمل. تحقق قبل حملة كبيرة.
- **`geo_precision`**: `exact` تعني إحداثيات المتجر من الصفحة، و`city` تعني أن
  الموقع غير متاح فوُضع مركز المدينة تقريباً — لا تعتمد عليها لزيارة ميدانية.
- **التحقق البشري**: البيانات كما نشرها الدليل، وقد تكون قديمة. راجع أول ٢٠ سجلاً
  يدوياً قبل أي حملة تواصل.
- **الشروط والأنظمة**: الأداة تحترم `robots.txt` وتُبطئ طلباتها، لكن جمع البيانات
  من موقع قد يخالف شروط استخدامه — راجعها، والأفضل طلب إذن أو شراكة بيانات.
  وفي التواصل التجاري التزم بنظام حماية البيانات الشخصية (PDPL) ونظام مكافحة
  الرسائل غير المرغوبة: عرّف بنفسك، واحترم طلب عدم التواصل.

## عند تغيّر بنية الموقع

الاستخراج مبني على إشارات ثابتة، لكن إن تغيّر شكل الصفحات جذرياً:
احفظ صفحة متجر واحدة في `tests/fixtures/`، وشغّل
`python3 -c "import sys;sys.path.insert(0,'.');import extract;print(extract.extract_store(open('الملف').read(),'الرابط'))"`
لترى ماذا يُستخرج، ثم عدّل `extract.py` — كل المنطق في دالتين: `extract_store`
و `extract_listing_links`.
